## Basic HTML Resume ##
- This project demonstrates basic web development skills using basic HTML tags to create a resume page.
- It shows basic information along with education, skills and work experience.

## Project Details ##
- The HTML page presents a fictional professional overview of John Doe with his details regarding his Education, Skills and Contact.
- This project is ideal for beginners to learn use of basic HTML tags and semantics.

## Technologies Used ##
- HTML.
- No CSS or Javascript.

## Features ##
- Used semantic HTML tags (header,section,footer,table)
- Clean and readble code
- Easy to understand
- Used table tag for structured data
